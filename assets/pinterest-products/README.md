# VELUCE Studio product-only Pinterest creatives
This folder is exclusively for images newly generated by the **14:00 six-product Pinterest rotation** (workflow: `veluce_six_product_cover_rotation_v1`). It is intentionally separate from `assets/pinterest/`, which contains the approved editorial image library used by the **06:00 four-article-Pin** automation.

- The 14:00 Work task continues generating **one NEW, original exact 2:3** product cover per successful run. Don't use the editorial stock images or the old first-cycle product images.
- Give each cover a unique lower-case filename such as `studio-product-outdoor-lighting-blueprint-c3-20261019.png`; preserve generated original bytes and aspect ratio.
- Each new product cover must display the exact relevant product name prominently in legible, elegant text, plus optional concise benefit-led headline; use warm attainable-luxury editorial style.
- The Work agent uploads the image bytes here with a supported GitHub file upload and points Buffer to the image itself using `https://raw.githubusercontent.com/Steynzville/Blogsite/main/assets/pinterest-products/<filename>`. The image does **not** need to be on velucedesign.com.
- Product Pins should click through to the live, correct Veluce **product-specific** page, not an article or Paystack checkout.
- Never publish a Pin from an image not actually uploaded and HTTP accessible. Don't claim Work-image creation or upload if missing from an automation run.
- Confirm publication by the official Buffer API `sent` status and its Pinterest external link before advancing the saved six-product cycle.
