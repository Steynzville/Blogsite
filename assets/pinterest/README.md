# VELUCE Pinterest source image library

Upload approved original artwork here to make it available to the Veluce publishing workflow, including vertical 2:3 pergola, fire-pit, exterior-lighting and other editorial images. These are **source assets only**, not published Pins.

- Keep original descriptive filenames (or assign a unique filename); avoid duplicates and unlicensed third-party images.
- Mix creative styles: both text-overlay and image-only assets are welcome.
- Before using an asset in a Pin, the agent should check prior publication history in `ops/state.json` and the Buffer ledger, choose a relevant monetised Veluce article, publish a *selected* image separately to `public/pins/` and verify its public URL.
- Never automatically post every image or assume an asset has been published simply because it lives in this folder.
- The Buffer Pinterest integration remains disabled for scheduled publishing until a live linked Pin has passed end-to-end verification.
